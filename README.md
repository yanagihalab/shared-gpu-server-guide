# 共用GPUサーバー利用ガイド

MacからLinuxの共用GPUサーバーを利用するための日本語ドキュメントです。ファイル転送、GPUの利用状況、tmux、ログ確認、3分音声サンプルのCLI実行をまとめています。

## 内容

| ファイル | 内容 |
|---|---|
| [共用GPUサーバーのコマンド集](docs/shared-gpu-server-commands.md) | SSH、SCP・rsync、利用者別GPU台数、監視、tmux、ログ、結果取得など |
| [3分サンプル音声の実行手順](docs/three-minute-sample-guide.md) | 構築済みのインタビュー処理環境で、先頭180秒の準備からCLI実行・結果確認まで |
| [GPU利用者集計スクリプト](scripts/gpu-users.sh) | 利用者ごとに計算用途・画面表示用途のGPU台数と番号を表示 |

コードブロックに記載した実行場所（Mac／GPUサーバー）を確認して使用してください。SSHの接続先は `GPU_SERVER` に伏せています。実際のIPアドレスまたはホスト名へ置き換えてください。ユーザー名、ファイル名、パスは今回の環境の例です。自分の環境に合わせて変更してください。

## GPU利用者の集計

GPUサーバー上でこのリポジトリのディレクトリへ移動して実行します。Bash、Python 3、nvidia-smi、psを使用します。

```bash
bash scripts/gpu-users.sh
```

10秒ごとに更新する場合：

```bash
watch -n 10 bash scripts/gpu-users.sh
```

Ctrl-Cで監視だけを終了します。GPU利用者集計スクリプトは状態を参照し、計算処理の起動や停止は行いません。

## 3分サンプルの前提

3分サンプルの手順は、LGPU01に既存のインタビュー処理アプリ、モデル、仮想環境、修正版設定が導入されていることを前提としています。このリポジトリにはアプリ本体、モデル、音源、文字起こし、認証情報は含みません。

GPUの空き表示は予約や利用許可を意味しません。共用サーバーの割当ルールに従い、実行中の処理を確認して使用してください。

## 確認範囲

文書内のBashコードブロック、集計スクリプト、埋め込まれたPythonの構文を確認しています。GPUサーバー上での全コマンドの実行を保証するものではありません。
